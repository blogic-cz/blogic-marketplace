# Evidence and Questions

Search nearest relevant artifacts first: implementation, tests, configuration, specifications, runbooks, decision records, and domain glossary terms. If no glossary exists, infer terms from nearby code and documentation; do not assume a repository path.

Use evidence to answer recoverable facts. Ask users only for preferences, priorities, risk tolerance, ownership, or information unavailable in artifacts.

Before each question, state:

- evidence found and source;
- unknown that remains;
- consequence of deciding it now.

Ask one neutral, answerable question. Avoid bundling choices or smuggling a recommendation into the wording.
