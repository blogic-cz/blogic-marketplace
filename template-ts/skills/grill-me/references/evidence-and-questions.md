# Evidence and Questions

Search nearest relevant artifacts first: implementation, tests, configuration, specifications, runbooks, decision records, and domain glossary/context. Nearest applicable context wins; if no glossary exists, infer cautious terms from nearby code/docs and label inference.

Use evidence to answer recoverable facts. Ask users only for preferences, priorities, risk tolerance, ownership, or information unavailable in artifacts.

Before each single question, state:

- evidence found and source;
- unknown remaining;
- consequence of deciding now.

Ask one neutral, answerable high-risk question. Do not bundle choices or present recommendation as fact. Prefer concrete scenarios that test boundary, failure, permission, data, and compatibility assumptions.
