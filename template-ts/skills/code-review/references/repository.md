# Repository Review Baseline

Before review, read `AGENTS.md`, applicable local instructions, contributor guidance, package/build configuration, and changed-surface standards. Identify base branch, required checks, architecture boundaries, generated-code policy, and domain terminology.

Use repository rules over generic preference. When they conflict or are unavailable, report uncertainty; do not invent standards. Load relevant skill/documentation only for touched surface. Record commands and outcomes as evidence.

Material means a concrete risk to behavior, security, data, contract, authorization, persistence, compatibility, or a documented architectural boundary. Generated files are reviewed only when their source input, template, or generation configuration changes.
